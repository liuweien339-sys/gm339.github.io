The Weien Kernel Project

for Xiaomi Mi 10T Lite / Note 9 Pro (gauguin) and other devices
个人项目 维护机型不算多 但是保持活跃
EFI ACPI DroidSpaces Kprobes BPF ReSukiSU sufus KPM KVM
Supported Devices

注意

  1. KVM & EFI 无法使用但是内核开了 正在尝试修复

核心特性

  1. kvm 硬件虚拟化 但是无法使用 内核支持
  2. susfs 增加 Root 隐藏
  3. 集成 KPM 动态内核补丁
  4. ReSukiSU Root 管理器

文件系统支持

  1. exFAT / NTFS (读写)
  2. CIFS / SMB 网络共享
  3. ISO9660 / UDF 镜像挂载

内核基础设施

  1. Kprobes / BPF
  2. DebugFS / KALLSYMS

刷入要求

  1. 支持 LineageOS 等类原生 ROM
  2. Recovery: TWRP / OrangeFox 都行

安装步骤

  • 重启进入 Recovery
  • 刷入最新AnyKernel3
  • 重启系统即可
