for Xiaomi Mi 10T Lite / Note 9 Pro (gauguin)
EFI ACPI DroidSpaces Kprobes BPF ReSukiSU sufus KPM OverlayFS

核心特性

  1. susfs 增加 Root 隐藏
  2. 集成 KPM 动态内核补丁
  3. ReSukiSU Root 管理器

文件系统支持

  1. exFAT / NTFS (读写)
  2. CIFS / SMB 网络共享
  3. ISO9660 / UDF 镜像挂载

内核基础设施

  1. Kprobes / BPF
  2. DebugFS / KALLSYMS

刷入要求

  1. 支持 LineageOS 23.2 等类原生 ROM
  2. Recovery: TWRP / OrangeFox 都行

  1. 下载
这个
  • 重启进入 Recovery
  • 刷入内核压缩包
  • 重启系统即可
